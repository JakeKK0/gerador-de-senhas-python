# Gerador de Senhas Aleatórias

Esse projeto tem como objetivo criar um gerador de senhas aleatórias por meio de Python diretamente pelo prompt de comando da máquina.

## 🚀 Começando

Essas instruções permitirão que você obtenha uma cópia do projeto em operação na sua máquina local para fins de desenvolvimento e teste.

### 📋 Pré-requisitos

De que coisas você precisa para instalar o software e como instalá-lo?

```
Será necessário utilizar um leitor de python ou uma IDE para desenvolvimento (IDLE, VSCode, etc.)
```

### 🔧 Instalação e Execução

**Instalação**

```
- Instale o arquivo projeto.py em uma pasta segura.
```
**Execução por CMD**
```
- Encontre a pasta do projeto e rode o seguinte comando: cd caminho/para/a/sua/pasta (troque as informações de acordo com o caminho para a pasta)
- Após isso, execute o seguinte código: python projeto.py
```
